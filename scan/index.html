Hinweise zum Tool

    
Der Scanner läuft vollständig in deinem Browser. Fotos werden nur im Arbeitsspeicher deines Geräts verarbeitet und nie an einen Server gesendet – die Seite darf technisch keine Verbindung zu anderen Servern aufbauen (Content Security Policy).

    
Open Source

    
Kantenerkennung und Bildverarbeitung: OpenCV (Apache 2.0). Texterkennung: Tesseract / Tesseract.js (Apache 2.0). PDF-Erstellung: pdf-lib (MIT). Alle Bibliotheken werden von dieser Seite selbst ausgeliefert.

    
Speicher

    
Nach dem ersten Besuch werden die Programmdateien im Browser zwischengespeichert, damit der Scanner auch offline funktioniert. Deine Dokumente werden nicht gespeichert.
