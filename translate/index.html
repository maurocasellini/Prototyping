Vertrauliche Texte, E-Mails oder Untertitel übersetzen – die Übersetzungs-KI von Mozilla läuft direkt in deinem Browser. Kein Text geht an Google, DeepL oder sonst einen Dienst.

So funktioniert’s

Warum hier niemand mitliest.

01

Die Modelle stammen von Mozilla

Mozilla – die Organisation hinter dem Firefox-Browser – hat für Firefox eine Übersetzung entwickelt, die ohne Cloud funktioniert. Genau diese Sprachmodelle verwenden wir.

02

Übersetzt wird auf deinem Gerät

Pro Sprachrichtung (z. B. Deutsch → Englisch) lädt dein Browser einmal ein kleines Modell von ca. 23 MB. Danach übersetzt dein Gerät selbst – auch ohne Internet.

03

Kein Dienst sieht deinen Text

Bei Google Translate oder DeepL geht jeder Text an deren Server. Hier wird nichts gesendet – die Seite darf technisch gar nicht mit anderen Servern sprechen.

Ehrlich gesagt: Die Modelle sind klein und schnell, aber nicht ganz so gut wie grosse Cloud-Dienste. Für Verträge oder Wichtiges bitte gegenlesen – dafür bleiben vertrauliche Inhalte wirklich vertraulich.

Hinweise zum Tool

Der Übersetzer läuft vollständig in deinem Browser. Texte werden nur im Arbeitsspeicher deines Geräts übersetzt und nie an einen Server gesendet – die Seite darf technisch keine Verbindung zu anderen Servern aufbauen (Content Security Policy).

Open Source

Übersetzung: Bergamot Translator (MPL 2.0) mit den Sprachmodellen von Firefox Translations (Mozilla, MPL 2.0). Die Modelle werden von dieser Seite selbst ausgeliefert und beim ersten Gebrauch pro Sprachrichtung geladen. Zwischen zwei Sprachen ohne direktes Modell (z. B. Deutsch → Französisch) wird über Englisch übersetzt.

Qualität

Die Modelle sind klein und schnell, aber nicht so stark wie grosse Cloud-Dienste. Für wichtige Texte bitte gegenlesen.
